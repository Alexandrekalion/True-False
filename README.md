# True e False em Python

Projeto educacional em Python criado para praticar valores booleanos e condicoes simples.

O exercicio usa um exemplo de aprovacao de financiamento para demonstrar como `True`, `False`, `if`, `else` e o operador `or` influenciam o resultado de uma regra logica.

## Objetivo do estudo

O objetivo e compreender o comportamento de valores booleanos em Python e observar como uma condicao pode aprovar ou negar um resultado conforme os valores das variaveis.

## Problema praticado

O projeto simula uma regra simples: se pelo menos uma das condicoes for verdadeira, o financiamento e aprovado; caso contrario, e negado. O foco esta no aprendizado da logica, nao na criacao de um sistema financeiro real.

## Como funciona

O script define duas variaveis booleanas e usa uma estrutura `if/else` para imprimir o resultado. Alterar os valores entre `True` e `False` muda o caminho executado pelo programa.

## Conceitos utilizados

- Valores booleanos `True` e `False`.
- Estrutura condicional `if/else`.
- Operador logico `or`.
- Leitura de fluxo logico.
- Primeiros cuidados com sintaxe em Python.
